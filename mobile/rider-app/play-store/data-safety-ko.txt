예

제3자에게 데이터를 판매하나요?
아니요

제3자와 데이터를 공유하나요?
아니요
(서버 운영용 Supabase, 푸시용 Firebase는 우리 대신 처리하는 업체입니다. 판매/광고 공유 아님)

수집 데이터와 목적
1) 이름
   - 수집함 / 앱 기능 / 필수
2) 사용자 ID
   - 수집함 / 앱 기능 / 필수
3) 전화번호
   - 수집함 / 앱 기능 / 필수
4) 기타 금융 정보 (정산·출금·명세서 조회)
   - 수집함 / 앱 기능 / 필수
5) 앱 상호작용
   - 수집함 / 앱 기능 / 선택 아님(앱 사용 기록)
6) 기기 또는 기타 ID (푸시 토큰)
   - 수집함 / 앱 기능 / 필수

수집하지 않음
위치, 사진, 연락처, 캘린더, 건강, 음성, 파일, 웹 방문기록, 광고 ID

예 (HTTPS)
